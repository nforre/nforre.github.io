# Journey Forrest — Portfolio

Personal portfolio web application for Journey Forrest, Computer Science student at Texas State University.

## Overview
- **Student**: Journey Forrest
- **Major**: B.S. in Computer Science (Minors in Business Administration and Applied Mathematics)
- **Institution**: Texas State University
- **Features**:
  - Theatrical curtain reveal with stage replay controls
  - Dynamic cursor spotlight tracking
  - Education, coursework & certifications showcase
  - Technical skills categorized by domain
  - Professional experience timeline
  - Project showcase with repository links
  - Fast contact actions (direct mailto & one-click clipboard copy)

## Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Typography**: Fraunces & DM Sans

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
